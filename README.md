# Superset

A simple, equipment-aware workout planner. Choose the equipment you have, build a full-body workout, swap exercises, and log your sets as you go.

## Run locally

Run `npm start`, then open <http://localhost:8000>. The app is a static site and has no dependencies to install.

Select your available equipment and choose **Build my workout** to create a new plan. Bodyweight exercises are always available. Adjust reps, time, or weight, add or remove sets, and check off completed sets. Swap an exercise to cycle through alternatives for the same movement using your selected equipment. Finishing a workout saves the completed exercises and set details to Activity and resets the checkmarks for your next session.

Your current workout, equipment selection, and recent activity are stored in your browser's local storage on this device. Clearing browser data will remove them.
